## Week 3: Advanced analysis and visualization

The Week 3 report explores a hypothetical logistics dataset containing 840 simulated shipments across 12 weeks. It uses Python to calculate delivery time statistics, late delivery rates, weekly shipment volume, transport costs, and correlations.

The report includes four charts:

- A line chart of weekly shipment volume
- A histogram of delivery times
- A bar chart comparing late delivery rates by zone
- A scatterplot of trip distance and transport cost

Each chart includes an interpretation and explains how it could help investigate logistics performance. The report also contains Python code excerpts and recommendations for a future analysis using real dispatch records.

**Report:** `Logistics_Week3_Analysis_Visualization_Report.docx`

**Data note:** All Week 3 shipment records and findings are simulated. They do not represent measured performance for a real company.
